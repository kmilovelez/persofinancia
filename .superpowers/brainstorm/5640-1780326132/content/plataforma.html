¿Cómo quieres acceder a PersoFinancIA?

Esto define la arquitectura base del proyecto

A

Web App (Next.js + Supabase Auth)

Accedes desde cualquier browser. Login con tu email. Desplegada en Vercel o similar. API keys nunca expuestas al cliente. Recomendado — escalable, seguro, moderno.

Pros

  • Acceso desde cualquier dispositivo
  • Auth real (no más key en HTML)
  • Fácil de iterar y desplegar

Contras

  • Requiere hosting (Vercel gratis)
  • Build step inicial
B

App Local mejorada (HTML + Supabase RLS)

Misma arquitectura actual pero con Row Level Security en Supabase y autenticación via magic link. Sin servidor propio. Corre en tu máquina.

Pros

  • Sin hosting ni build
  • Cambios rápidos

Contras

  • Solo en tu PC
  • Token JWT en localStorage (riesgo XSS)
  • Menos escalable
C

Electron / Desktop App

App de escritorio instalable en Windows. UI web dentro de una ventana nativa. Datos locales + sync a Supabase.

Pros

  • Funciona offline
  • Experiencia nativa

Contras

  • Más complejo de mantener
  • Solo en tu PC
  • No accesible desde móvil
